## Original direction

An editorial engineering documentary: near-black paper, off-white large type, serif inflections, monospaced technical annotations, subdued cyan for event flow and the warm amber already present in the supplied hero portrait. A large portrait bleeds into the hero, behind offset two-line typography. Small metadata establishes engineering focus without terminal imitation. Fine grid lines and grain add depth without WebGL.

The visual rhythm alternates asymmetric project showcases, a full-width interactive console, minimal contribution rows, a vertical journey, portrait-led biography and a compact capability map. Three signatures: the layered warm portrait reveal, the event lifecycle with optional failure and retry, and project-specific architecture artwork. Project art is labeled conceptual, never presented as screenshots or real telemetry.

The formal portrait supports biography. The illustrated suit portrait and supplied desk composition appear as creative imagery; interests and possessions visible in the illustration are not treated as factual claims. No unrelated portraits or fabricated event photographs are used.

Native scrolling, desktop-only cursor enhancements, reduced-motion fallbacks and an intentionally rearranged mobile hero keep the experience readable. Recruiters can use Quick view, anchored navigation, direct project routes and the downloadable supplied resume.
